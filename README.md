# 盘库 · 扫码盘点

纯前端静态应用（无后端）。扫码、导入 Excel、盘点、差异核对、多人结果合并、导出 Excel。
线上地址：https://mr-noc.github.io/PANKU/

## 这次更新（v33）

### 1. 多人合并：按区域算，不再翻倍/漏算

- 新增「区域」：一个货架 / 一个堆头 = 一个区。
- 在「菜单 → 区域管理」新增区域，点「打印区域码」打印 Code128 贴纸（内容是 `ZA01` 这种，带 Z 前缀，和商品码隔离）。
- 店员到一片区域先扫区域码（对准停 0.5 秒），顶部会显示当前区域，之后扫的商品都记到该区。
- 合并规则：
  - 同一商品**不同区域** → 数量相加；
  - 同一商品**同一区域**、多个人盘 → 取最大值并标「待核对」；
  - 没扫区域码的 → 按老规则（同值采纳 / 异值冲突）。
- 合并时会自动按「设备 + 盘点任务」去重，同一台手机重复导出不会重复计。
- 导出 Excel 增加「区域明细」列和「区域汇总」工作表。

### 2. 扫码：连续扫更快，且不会连扫两个

- 解码只跑取景框区域（ROI），不再每 2 秒整帧转 JPEG，主线程不卡。
- 新增「离场闸门」：同一个条码在框里停留多久都只计 1 次；必须移开约 0.4 秒后再出现才 +1。
- 条码归一：UPC-A 12 位自动补前导 0 成 EAN-13，和表格里的 13 位能对上。
- 区域码优先识别：扫到 `ZA01` 这种码会切区，不会当成商品。
- iOS / 低端机走「半自动」：对准后点屏幕任意处 +1（设置里可以强制切换）。
- 微信里打开会提示「点右上角 ··· → 在浏览器打开」，并可一键复制链接。

## 本地运行（电脑）

```bash
python3 server.py 8765
# 浏览器打开 http://127.0.0.1:8765/
```

> 摄像头扫码要求 HTTPS 或 localhost；http://127.0.0.1 满足条件。
> 电脑没有摄像头也能用：USB 扫码枪（键盘模式）直接扫，App 支持键盘输入条码。
> 手机连同一 Wi-Fi 可以打开 `http://电脑IP:8765/`，但浏览器只在 HTTPS 或 localhost 下允许相机；手机端建议直接用 GitHub Pages 的 https 地址。

## 部署

仓库 `main` 分支根目录就是站点，推送到 GitHub 后 Pages 自动构建，约 1 分钟生效。
构建相关文件：`index.html`、`app.css`、`js/`、`lib/`、`icons/`、`manifest.webmanifest`、`sw.js`、`.nojekyll`。

## 目录

- `index.html` 入口
- `app.css` 样式
- `js/core.js` 状态、IndexedDB、工具、区域数据
- `js/import.js` 表格导入（门店、销售仓过滤、短码判定、Z 前缀校验）
- `js/scan.js` 相机扫码、拍照识别、ROI 解码、离场闸门、半自动
- `js/views.js` 界面与页面、区域管理/打印
- `js/export.js` 导出 Excel/CSV、打印标签、区域汇总
- `js/merge.js` 交接文件、多人结果合并、冲突核对
- `js/main.js` 启动与全局事件
- `lib/` 离线依赖：xlsx、zxing、jsbarcode
- `sw.js` 离线缓存
- `server.py` 本地静态服务器

## 数据说明

- 数据存在**当前浏览器**的 IndexedDB 里，按「浏览器 + 域名」隔离；换浏览器、换设备看不到之前的数据。
- 换浏览器：用「复制整份盘点（换浏览器用）」→ 另一个浏览器「从剪贴板接收」。
- 多人盘点：各手机「导出交接文件（.json）」，在电脑上先导入清单，再「合并多台手机的结果」。
- 升级版本后如果界面没变，设置里点「修复加载 / 强制更新」。
